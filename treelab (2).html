📖 Botanical Visual Primer & Core Invariants

Quick reference covering essential tree properties following academic university standards.

Invariant 01

Tree vs Graph

A Tree is a connected, acyclic directed graph with a unique root node. In an N-node tree, there are always exactly (N - 1) edges. No cycles are permitted.

Edges = N - 1 | Cycles = 0
Invariant 02

Height vs Depth

Depth: Number of edges descending downward from the Root to the node (Root depth = 0).
Height: Number of edges on the longest downward path from the node to a leaf (Leaf height = 0). Height of tree = Height of root.

Depth: Root → Node | Height: Node → Leaf
Invariant 03

Strictly Binary (Full) Tree

Every internal (non-leaf) node has both a left and right child. Out-degree is always either 0 or 2, never 1!

Degree(node) ∈ {0, 2}
Invariant 04

Complete Binary Tree

Every level except possibly the last is completely filled, and all nodes in the last level are as far left as possible with zero gaps.

No empty holes before the last element!
Invariant 05

AVL Balance Factor

For every node in an AVL tree, the Balance Factor is defined as:
BF = Height(Left Subtree) - Height(Right Subtree).
Valid AVL invariants require $BF \in \{-1, 0, +1\}$.

|BF| ≤ 1 (LL, RR, LR, RL rebalancing)
Invariant 06

Red-Black Invariants

1. Every node is Red or Black.
2. Root is Black.
3. Red nodes cannot have Red children (No Red-Red violations).
4. Every path from a node to its descendant leaves contains the same number of Black nodes.

Uniform Black-Height on all paths
